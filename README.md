# 💰 Finny — финансы Маши и Димы

Личный учёт трат по категориям + контроль платежей за студию в Дубае (Berkeley Square, Prestige One).

## Как устроено

- **Фронтенд**: Vite + React (`src/`), деплой на Vercel.
- **База**: Supabase (проект «Job», таблицы с префиксом `finny_`). Доступ только после входа и только для email из `finny_members` (RLS).
- Схема — `supabase/migrations/`, начальные данные — `supabase/seed.sql`.

| Таблица | Что хранит |
|---|---|
| `finny_transactions` | операции: дата, название, сумма (минус — расход), валюта, категория, кто платил, источник |
| `finny_categories` | категории (эмодзи, группа, тип: расход/доход/перевод) |
| `finny_rates` | курсы валют к рублю |
| `finny_budget` | месячный план: доходы, накопления, статьи расходов |
| `finny_property` | квартира в Дубае: цена, сборы, даты, сколько копим в месяц |
| `finny_dubai_plan` | график застройщика (62 платежа) |
| `finny_dubai_payments` | фактические платежи: AED + сколько рублей внесли Маша и Дима |
| `finny_members` | кто имеет доступ (email, кто это, админ) |

## Вкладки

- **Обзор** — траты месяца по категориям и людям, ближайший платёж за квартиру.
- **Траты** — таблица операций: дату, название, категорию, кто, сумму можно менять прямо в ячейке; добавление и удаление.
- **🏙️ Квартира** — прогресс оплаты, опережение графика, вклады Маши и Димы, прогноз на 12 месяцев.
- **План** — бюджет и план vs факт.
- **⚙️ Админка** — редактирование платежей за квартиру, категорий, курсов, плана, графика и доступа.

## Процесс заполнения

1. Присылаешь видео/скрины/PDF-выписки из банков.
2. Claude переносит операции в `finny_transactions` и проставляет категории.
3. Категории и названия можно поправить в интерфейсе — сохраняется сразу.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

## Деплой на Vercel

Import Git Repository → фреймворк определится как Vite (настройки в `vercel.json`).
Переменные окружения необязательны: URL и publishable key Supabase уже прописаны в `src/lib/supabase.ts`
(при желании переопредели `VITE_SUPABASE_URL` / `VITE_SUPABASE_PUBLISHABLE_KEY`).
Данные защищены логином Supabase; сам сайт без логина показывает только форму входа.
