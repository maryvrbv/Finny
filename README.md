# 💰 Finny — финансы Маши и Димы

Личный учёт трат по категориям + контроль платежей за студию в Дубае (Berkeley Square, Prestige One).

## Как устроено

Данные лежат в git как JSON — это единственный источник правды. Сайт статический (Vite + React), деплоится на Vercel.

```
src/data/
  settings.json              базовая валюта (RUB), курсы валют, имена
  categories.json            категории трат (id, название, эмодзи, группа, тип)
  budget.json                месячный план: доходы, накопления, статьи расходов (из листа «📊 Расходы»)
  dubai.json                 квартира: цена, сборы, график застройщика (62 платежа), фактические платежи Маши/Димы
  accounts.json              счета/карты (заполним, когда будут актуальные остатки)
  transactions/YYYY-MM.json  операции за месяц — новые файлы подхватываются автоматически
```

Операция (`Transaction`):

| поле | пример | смысл |
|---|---|---|
| `date` | `2026-11-03` | дата |
| `title` | `Перекрёсток` | название траты |
| `amount` | `-2350` | минус — расход, плюс — доход, в валюте операции |
| `currency` | `RUB` / `AED` / `USD` | валюта |
| `categoryId` | `groceries` | категория из `categories.json` |
| `who` | `mary` / `dima` / `joint` | кто платил |
| `source` | `видео 1, Т-Банк` | откуда взяли |

## Правки в интерфейсе

Категорию, название и «кто платил» можно поменять прямо в таблице «Траты», категории — во вкладке «Категории».
Правки сохраняются в браузере (localStorage) поверх данных из git. Кнопка **«Экспорт JSON»** выгружает
итог — его можно прислать Claude, чтобы закоммитить. Позже можно подключить базу (например, Supabase), чтобы правки сразу были общими для обоих.

## Процесс заполнения

1. Присылаешь видео/скрины из банковских приложений.
2. Claude переносит операции в `src/data/transactions/YYYY-MM.json` и проставляет категории.
3. Пуш в git → Vercel пересобирает сайт.

## Запуск

```bash
npm install
npm run dev      # локально
npm run build    # сборка в dist/
```

## Деплой на Vercel

Import Git Repository → фреймворк определится как Vite (настройки в `vercel.json`).
⚠️ Здесь личные финансы: включите **Deployment Protection** (Vercel Authentication или пароль) и держите репозиторий приватным.
